# NYS Canal System

GIS.NY.GOV [NYS Canal Corporation](https://gis.ny.gov/gisdata/inventories/member.cfm?organizationID=5130)

- [NYS Canal Locks](https://gis.ny.gov/gisdata/inventories/details.cfm?DSID=862)

  > Statewide file showing the location of all Canal Locks along the NYS Canal
  > System. The data is in Zone 18 of the UTM grid/projection system (Zone 18
  > is extended to cover New York State entirely in a single grid zone).

  [Metadat](https://gis.ny.gov/gisdata/metadata/canal.canal_locks.xml)

- [NYS Canal System](https://gis.ny.gov/gisdata/inventories/details.cfm?DSID=863)

  > Statewide file showing the boundary of the NYS Canal System. The data is in
  > Zone 18 of the UTM grid/projection system (Zone 18 is extended to cover New
  > York State entirely in a single grid zone).

  [Metadata](https://gis.ny.gov/gisdata/metadata/canal.canal_system.xml)
